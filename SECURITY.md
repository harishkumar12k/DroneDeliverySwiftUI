# Security Policy

We release patches and security updates for the current active version:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do NOT open a public GitHub Issue.**
2. Go to the repository's **Security** tab on GitHub.
3. Click on **Advisories** in the left sidebar.
4. Click **"Report a vulnerability"** to submit a private disclosure.

This allows us to review, verify, and resolve the security issue privately before making it public.
